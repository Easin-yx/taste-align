# 二维审美地图：产品与验证方案

方案修订日期：2026-11-06。所属产品：[同频产品中心](../PRODUCT.md)。实际进度与验证证据见 [当前状态](STATUS.md)。

**当前用户决定**：保留像调色盘一样的二维视觉探索，以已经搭配好的完整界面为选择单位。产品负责阅读/操作底线和整体协调，用户只判断更喜欢哪种效果；不要求用户解释局部、不让用户承担逐项搭配工作。方案定义见 [视觉题 v0.2](QUESTION-DEFINITIONS.md)。下列数量、标签和轴仍需校准，不表示已经制作或上线。

## 1. 要解决的具体任务

帮助非设计用户在当前用途下找到愿意使用的完整设计方向，再将实际画面、动作与协调关系交给 AI。首轮用原创手机内容浏览页面及另一份内容/页面复核，不声称覆盖所有产品和艺术风格。

例如用户喜欢悬浮质感，产品展示已经处理好文字、背景、边框、阴影和光线关系的整页变体。用户只选完整效果；参数记录由作者负责，不能据此断言用户分别喜欢其中每个技术值。

## 2. 设计质量、偏好与题目的分工

| 层次 | 责任与作用 |
| --- | --- |
| 阅读与操作底线 | 所有候选必须满足；不由用户投票决定 |
| 搭配协调与制作完整度 | 样本作者逐套审阅；是专业判断，不是唯一正确风格或满意保证 |
| 气质与个人偏好 | 用户通过完整实例选择；不同合法风格都可精良 |
| 可控参数 | 内部用于制作、联动、还原和检验；不是默认用户问卷 |
| 适用范围与迁移 | 以具体内容/任务和复核证据限定，不能推广为永久审美画像 |

当前 D01 整体方向、D02 完整配色、D03 阅读排版、D04 表面空间、D05 操作体验、R01 迁移与 C01 确认的具体定义，只在 [视觉题规范](QUESTION-DEFINITIONS.md) 维护。旧逐参数 Q/X 题已退出默认方案，历史证据不重解释。

每题先声明目标变化、为协调而联动的变化、保持项、候选与父方案关系、允许推断及边界。多参数联动时只能推断该条件下偏好整套实例，不能声称找到了独立参数的因果权重。内部校准仍可控制单变量，不等于要求用户逐项设计。

## 3. 地图与预设样本

D01 建议先准备 4–6 套品质相当、内容/功能相同的完整方向；不能只是一个模板换色，也不能靠图像或制作质量不公平的差异诱导选择。细化题使用少量协调变体，只有两组变化确实自然、有序时才采用有序网格；否则用二维画布中的离散位置。不硬凑九宫格，不显示虚假坐标精度。

每个位置代表已编写且经检查的完整配方，允许使用确定性组件渲染；不依赖实时生图，不将任意参数乘积当成合法方案。没有协调候选时保留当前方案、换已制作的一组或结束，不暗改别处凑结果。候选数量根据手机可辨性和负担校准。

每个样本有版本、实际画面/动作、全部配方、联动清单、许可与质量检查记录。有限样本吸附选择，过渡混合帧不成为新样本；素材加载失败保留当前方案，不算拒绝。动效要能播放/暂停/重播，静帧不代替动态确认。

## 4. 用户完整走一遍

| 环节 | 用户动作 | 记录与边界 |
| --- | --- | --- |
| 用途 | 沿用项目信息，必要时简单选择一次 | 不逐题填范围，不强制自由文字 |
| 整体起点 D01 | 在二维画布看完整页面，选接近的一套 | 确认完整实例为当前起点，不确认每项属性 |
| 细化 D02–D04 | 在当前完整页面中选择搭配好的变体，可跳过 | 确认才产生新的当前方案版本，历史保留 |
| 操作 D05 | 实际打开/返回，选择舒服的完整动作 | 只记录已体验任务，未播放的动态仍未确认 |
| 换内容 R01 | 看当前设计迁移到另一页/内容，认可或选替代 | 条件不同可形成分支，不要求解释原因 |
| 确认 C01 | 将当前完整实例作为参考，也可带未知项结束 | 验收已有完整效果，不是第一次拼装答案 |
| 交接与核对 | 导出既有资产包，将新稿带回核对 | 人工确认、返工与旧评定过期继续复用 |

“都可以”“看不出差别”“都不合适”“跳过”保持独立语义。未选方案不自动成为讨厌，鼠标停留不代表确认；个人参考/文字仍是自愿扩展。默认约六次主题/复核判断、最多两次换组或额外修正，再做 C01；所有分支共享预算，可提前结束。没有替代素材就诚实保留未知，不能转成必填设计问卷。

## 5. 状态、修改与冲突

- 预览与当前生效实例分开；移出画布、拖动松手或移向确认按钮仍保留候选；明确取消才恢复当前实例。
- 确认协调变体后形成父子版本；当前方案是一套完整结果，旧方案留在历史，可撤回，不能将每次选择的全部参数累加成独立硬性偏好。
- 用户选择新整体方向时保留旧分支；原分支细化不自动套用，受影响的核对过期。
- 不同内容允许不同方案；未解决差异以场景分支或待复核交接，不取平均、不伪造同一全局风格。
- 题目、素材或配方升级保留旧版本证据，不静默重解释旧 Q 题或线上 A/B 答案；无权自动升级为整套确认。
- 无模型识图/原因推断。只据明确选择、版本、兼容关系及用途处理状态，不能声称发现所有矛盾。

## 6. 桌面与 iPhone 的操作

桌面采用地图与完整大预览并列，手机采用用途、完整预览、地图、确认的顺序。预览在手指上方，内容可滚动或等比例查看；地图外正常滚动，点击替代拖动，键盘和辅助技术有等价入口。短屏不挤满多张小截图，不缩小到文字无法辨认。

主触控目标至少44px；颜色不单独传状态，外壳保持中性，避免给样本染色。尊重减少动态效果，当前动效单独播放；不中断比较、不用反复庆祝增加负担。桌面手机尺寸检查与 iPhone 真机验收分开记录。共用 [设计规则](../DESIGN.md)。

## 7. 怎样始终保持协调

协调在 D01 就成立，D02–D05 的每个候选也要成立；不把审美搭配推迟到最后。配方联动可以改变多个参数，但每一步都基于当前完整实例和已审阅的兼容变体，不能自动组合任意旧答案。

默认保留已认可的其他关系；确需明显改变字体、构图等超出本题重点的内容，应作为更广的整体变体展示，而非偷偷修正。用户确认的是看见的新整体，历史依然可追溯。没有合格配方不强行产出，质量门槛也不等于只提供作者喜欢的一种风格。

这不是自动生成任意完整 App。只提供已覆盖任务的完整代表性界面、动作与迁移检查；未覆盖的页面和模式保留未知。

## 8. 交给 AI 的内容

文件职责、约束来源与强度、逐题证据映射、可选 skill 边界和验收格式以 [设计约定与 AI 交接规范](DESIGN-HANDOFF.md) 为准。沿用已有导出文件名，避免重复简报；同一快照生成文档、配方和资产引用，不能把整套选择拆成每个参数的独立要求。

复用 Markdown + JSON + 本地资产 ZIP，包含题目/父子方案/配方版本、当时的完整画面与动作、目标与联动变化、内容/用途、当前实例和历史、明确拒绝、未知项以及核对记录。

分开“用户选择整套实例”“为还原整体提供的参数与关系”“尚未确认的范围”。例如用户选择 B3 整页配色，接手者应保持其颜色角色与排版关系，而不能写成用户分别要求每个颜色值。未进行的动态/跨页面验证不能因 C01 点击自动变为通过。

样本参数可用于还原，但不是每个都经用户独立批准。已确认当前版本与可回溯历史要区分，不能导出互相冲突的多套硬性要求。

## 9. 验证与推进条件

| 检查 | 要解决的问题 | 推进或修订条件 |
| --- | --- | --- |
| 候选质量与公平 | 内容、功能、素材、制作投入是否相当；所有变体是否协调 | 先检查硬性质量和专业搭配，不合格样本不上图，不强凑角点 |
| 早期校准 | 3–5位非设计用户能否只看画面选择，方向是否过窄 | 访谈仅用于研究；理解不清就改图/题，不加日常必填解释 |
| 连贯探索 | 点选、拖动、撤销、断点恢复与短屏是否完整 | 不需要自由文字/个人参考也能交接；选择丢失或必须研究者指导则先修 |
| 迁移与真实交接 | 换内容能否维持整体关系，接手者能否还原意图 | 比较直接描述、旧 A/B 与新版整体探索，尽量控制任务、模型和预算，不预设新版优胜 |
| 覆盖与疲劳 | 用户是否反复被迫选“最不差”，更大题库是否增加负担 | 记录拒绝/跳过与耗时，先修方向覆盖和分组，不盲目扩图库 |

小样本用于发现问题，不对外发布泛化准确率；审阅者认可、自动检查和用户真实喜欢分开。未经真人/真机验证的部分保持待办，已有版本匹配的证据可复用，受影响的变化才重测。

## 10. 开发计划：从研究支持到可用闭环

本节维护后续实施阶段的任务与验收依据；完成状态只记录在 [STATUS.md](STATUS.md)。2026-11-10 当前任务仅完善交接规范、题目映射及关联文档，不执行以下开发或发布步骤。以下数量、阶段与技术方案是执行建议，不是研究已证实的效果。后续实施复用既有产品，不另造孤立演示，不把每个阶段变成用户必须点头的关卡。

### 10.1 后续实施目标与范围

交付可在统一入口使用的下一版：选择当前用途 → 完整方向选择 → 整页协调细化 → 操作与迁移复核 → 确认交接 → 新稿核对。首轮围绕一个原创、包含文本/图片/卡片/按钮的代表性手机界面，另备内容和布局不同的复核页面；网页扩展不先承诺同样有效。

保留现有项目、A/B 历史证据、自愿参考、导入导出、核对和中英文能力。旧 A/B 作为兼容路径和比较基线，不让用户重新做题或把旧答案强行转换成二维坐标。暂不加入实时生图、账号、云端模型、自动生成完整 App、训练个人模型或复杂贝叶斯优化。

下一版分两层完成：工程闭环完成后可发布为明确标注范围的试用版本；只有真实使用验证后才讨论“更有效”。真人招募或设备不可得时记录阻塞，不用子 Agent 模拟人类偏好作为证据，也不无限搁置已授权的工程工作。

### 10.2 阶段与验收

交接规范带来的阶段补充：P0 按输出要求倒查逐题证据，不增加技术参数必答题；P1 制作完整样本时同步写配方、资产版本与要求映射，并准备 D01→D02→C01 的实际交接切片；P2 扩展同一事实记录和兼容格式；P5 按 [交接规范](DESIGN-HANDOFF.md) 实现已有五类文件的生成、追溯和核对，不另造平行导出系统。通用 skill 是可选后续适配，不是本轮前置。

| 阶段 | 具体工作与产物 | 依赖与验收条件 |
| --- | --- | --- |
| P0 研究转题目 | 按视觉题 v0.2 定义 D01–D05、R01、C01；记录完整候选、目标/联动/保持项、质量门槛和推断边界 | 不把搭配工作交给用户；来源与假设分开，类别不伪造连续轴 |
| P1 样本与交互校准 | 先制作 D01 的少量完整方向，再为其中一个方向制作 D02 的整页配色变体，内部贯通 D01→D02→C01；解决触屏、短屏与版本确认 | 相同内容/功能，品质相当；每套先过阅读/操作与协调检查。旧 Q05 材质九宫不再是首个交付，轴或数量不成立就调整，不强凑网格 |
| P2 证据与兼容底座 | 定义带版本的题目、完整方案父子关系、兼容配方、联动清单、回答、适用范围与确认。区分临时预览、确认、都可以、看不出差别、都不合适、跳过、冲突与过期。扩展现有模型、存储和备份格式 | v0.1 项目和资产无损保留；旧答案不被重解释；导入失败不覆盖数据；新旧备份分别验证。参数是样本属性，不能伪造为用户硬性要求 |
| P3 连贯视觉选择 | 新项目使用视觉题主路径；用途通过少量选项或已有项目信息确定，不强制写说明。支持移动/点击预览、独立确认、返回改选、撤回、提前结束与断点恢复。必要复核用预编分支，不进行模型推理 | 不上传素材、不填理由也能完成。首轮约 6–8 题含复核作为负担上限试验；连续两次都不合适可换组或结束。旧项目自愿进入新路径；答题不需要懂坐标数值 |
| P4 协调整体与迁移确认 | 维护每步的完整实例与兼容变体，完成 D05 操作、R01 新内容复核和 C01 确认；满意方向才细化，方向不合适则换组或结束 | 不任意拼参数；保持父子版本与场景分支。确认新实例不等于独立认可每个属性，不静默替用户改变旧选择；缺失映射或候选时保留原版与未知 |
| P5 交接与核对接通 | 扩展已有 Markdown/JSON/ZIP：纳入题目定义、版本、所选图/动效、示例参数、作用范围、拒绝/未知/冲突和整体确认。新稿复用现有人工核对与返工导出，受影响的旧确认失效 | 离线打开资产包能看到当时所选内容；重导入后语义和资产一致。来源与用户明确选择可区分；不依赖线上最新图库重写历史；不把人工判定称为自动审美检测 |
| P6 验证、开源与同入口发布 | 运行功能/浏览器/无障碍检查；验证中英文、短屏、减少动态效果、离线资产与加载失败。完善 README、题库贡献规范、许可清单与样例包；独立只读审查后更新现有公开入口 | 发布前验证生产构建与备份兼容，发布后复核公开地址完整闭环与版本。明确桌面手机尺寸与 iPhone 真机验证的区别；未验证部分如实列出，不以部署成功代替可用 |
| P7 有效性验证与迭代 | 复用 P1 按第 9 节尽早开展的 3–5 人探索性观察，再比较直接描述、原 A/B、二维题三条路径的交接结果。用未参与题目制作的内容与接手者；尽量控制任务、模型、预算并调整顺序 | 小样本只用于发现问题，不发布泛化准确率。记录是否理解、放弃/拒绝、整体认可、交接偏差、澄清轮次和新页面偏好；没有优势先修题目与组合，不扩图库或训练模型 |

### 10.3 贯穿各阶段的体验标准

“轻松、精致、可把玩”是交付条件，不放到功能全部完成后再美化。地图、大预览、选择标记、页间过渡与导出反馈共用设计规则；用户始终知道当前预览与正式选择的区别。动效服务于连续性，不阻碍反复比较，不用夸张庆祝增加负担。中性外壳避免影响样本配色判断；同时通过排版、间距、触感反馈与细节保持品质。

P1 就检查触屏比较与短屏，P3 检查不中断的连续选择，P4 检查整套界面和操作的协调，P6 检查最终公开版本。精致程度由实际视觉/操作审阅与用户反馈验证，自动测试只能检查功能和部分可访问性；不能以“测试全绿”宣称艺术品效果已达成。

### 10.4 第一题的制作清单

第一批制作 D01 完整方向及一个方向的 D02 整页配色。每套都有相同内容/功能、完整布局与配色、合法字体/素材、可还原配方、质量记录、版本与推断边界；D02 另记录父方案、目标和联动变化。先证明从完整起点到协调细化能成立，再扩展材质与动效，不先大量制作裸参数网格。

这些样本同时提供设计约定的真实资产、配方和逐条核对清单；用一个 D01→D02→C01 包让接手者完成约定范围内的界面，记录误解与缺口。只有文字示例时不可标记真实交接通过，不等 P5 才补做样本制作资料。

题库编写规范应让外部贡献者能添加一题并完成验证；开源内容包括组件与原创样本，不默认再分发论文截图、完整问卷或外部字体。论文和算法引用与软件许可分别核对。

### 10.5 并行安排与集成责任

- 主执行者负责题目语义、共享数据约定、整合、验收与唯一发布；不能以各子任务通过替代完整任务验证。
- P0 的研究/题目梳理与 P2 的既有数据兼容盘点可并行。题目数据约定稳定后，样本制作、选择界面和导出兼容可按文件边界并行。
- P3 的题序依赖 P1 有可用样本与 P2 稳定证据格式；P4 必须基于经审阅的完整方案及兼容关系，不能自动拼接所有参数，也不在覆盖未定时硬编码唯一风格。
- 无障碍、触屏和保存错误验证从首个贯通切片开始，不推迟到发布前；真人校准尽早进行，等待外部条件时可继续兼容、导出及可靠性工作。
- 先打通“完整方向→一次整页细化→保存→交接→导入→核对”的纵向切片，再扩完整题序。内部切片不是新的公开演示入口，也不是要求用户反复验收。

### 10.6 必测风险与回退

| 风险 | 必须覆盖的行为 |
| --- | --- |
| 预览被误保存、移出丢候选 | 鼠标移出、手指松开、点击确认、返回、刷新与取消各自状态正确 |
| 旧数据或备份损坏 | 使用合成 v0.1 项目/资产固定样例，验证升级、重复导入、损坏/未来版本包、保存失败和容量不足；失败保留当前数据 |
| 素材升级改变历史含义 | 已选样本保留其版本和可移植资产；废弃题不清空旧证据，需复核时明确标记 |
| 改答案后仍用旧结果 | 改选、撤销与整体修正只让相关核对过期；不同项目/用途之间不相互污染 |
| 手机上卡顿或操作冲突 | 只加载当前/相邻样本，限制同时播放；检查 iPhone 短屏、滚动与拖动冲突、safe area、恢复前后台、导出。性能实测后记录，不预先宣称流畅 |
| 视觉形式制造假确定性 | 都可以/看不出/不合适/跳过不等价；未选样本不自动列为讨厌；兼容组合未确认不写成完整方案 |
| 回退导致新数据不可读 | 每个发布形成可回退版本，采用非破坏兼容策略；旧版对新格式拒绝写入并提供恢复说明。回退前导出受影响的新格式数据，不能仅回滚网页就宣称全部安全 |

### 10.7 执行与验收约定

外部验证由主执行者准备任务、样本版本、记录表并组织可获得的参与者与设备，不默认让产品发起人承担全部测试。P1 按第 9 节开展的真人校准，在样本和题义版本未变时直接计入 P7，不重复招募；改变轴、目标变量、素材或题义后只重测受影响的题与组合。跨页面迁移和真实交接仍需各自证据。拿不到参与者或真机时标记“工程完成、真人校准待办/真机待验”，可继续工程并发布标明边界的试用版，但不能将相关验证标为通过。不得未经授权联系他人、支付招募费用或上传用户资料。

兼容方案补充：不得假设已打开的 v0.1 代码会遵守新版拒写协议。当前保存逻辑直接按项目编号覆盖记录；P2 应优先评估隔离新版记录空间并保留迁移前副本，确保旧页写入不会覆盖新证据，同时识别并提示并行旧版编辑，不能静默丢弃修改。P2/P6 必测新旧标签页同时打开、升级后旧页延迟保存与删除；这些是计划中的防护要求，尚未修复或运行验证。

后续进入实施阶段时，执行者自主处理常规实现、文案、排障、版本与同入口发布，不逐步索要确认。仅扩大范围、引入费用/外传数据或改变已确认主体验时，提出一个关键决策。对外报告分开：已开发、已本地验证、已发布、已真机验证、已真人验证；未取得的证据保持待验证。

本计划没有把复杂优化算法设为前置，也没有承诺固定天数或固定题数达到审美理解。优先交付有明确边界、轻松可用的完整闭环，再依据 P7 的证据决定扩大题库、引入自适应选题或保留二维为可选路径。

## 11. 目前最重要的未知项

- 用户是否受题材或不等量制作质量诱导，而非在公平的完整方向之间选择？
- 少量完整方向是否覆盖过窄；更大图库是否只增加选择疲劳？
- 同一用户换用途或换一天后偏好是否变化？应支持更新，不能当成“测试不诚实”。
- 预设样本是否把用户带入我们的风格，而遗漏了更独特的个人方向？个人参考和拒绝入口必须保留。
- 联动配方是否真的维持协调；AI 是否把整套认可误写成独立参数硬性规定？需要真实交接复核。
- 可播放样本和素材数量增加后，iPhone 加载、滑动、导出是否仍然轻快？未测之前不许承诺性能。

设计流行变化不要求重建全部框架：可控属性和约束作为较稳定的底层，题目与样本按版本更新，新类别作为扩展。不能假设底层永远完整；新交互形式需要新增要素时，重新验证适用边界，旧项目仍保留当时的题目和资产版本。

研究基础和相关项目见 [研究依据](RESEARCH.md)。这些材料启发方法，不证明本产品已经有效，也不提供对全部审美的完备分类。
