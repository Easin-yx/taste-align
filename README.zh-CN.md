# Taste Align · 同频

**把说不清的审美，变成 AI 能理解、能核对的设计要求。**

[在线体验](https://easin-yx.github.io/taste-align/) · [English](README.md)

你不需要知道“缓动曲线”“字体层级”这些术语。看到差别，指出喜欢什么，把理由和画面一起交给 AI。

## 四步完成一次对齐

1. **看差别**：同一内容只换材质、色温、疏密、轮廓或动作；可以选 A、B、都不喜欢，或跳过。
2. **标记参考**：上传自己的截图或短视频，指出某个位置/时刻值得借鉴、必须保留或应当避免的细节。
3. **交给 AI**：下载包含简报、原始图片、位置、项目备份的 ZIP。把它交给 Codex、Claude Code 或其他能读图和文件的 AI。
4. **核对新稿**：将新稿和参考放在一起，按原来的要求逐条检查；换稿、改要求后，旧的确认自动过期。

工具不会自动识图、调用模型或给审美打分。它提供的是更清楚、更完整的设计输入。无需账号和 API，数据保存在本机浏览器；没有云同步。导出包也能导回来继续编辑。

## 本地启动

安装 Node.js 22.12+（推荐24 LTS），然后：

```sh
npm ci
npm run dev
```

访问 `http://localhost:5193`。`npm run build` 生成静态站点 `dist/`，可独立部署。

## 交接给 AI

解压到开发项目中，然后说：

> 先读取 DESIGN_BRIEF.md，再看 assets/ 里的参考图和标记位置。用同一内容做一个代表性交互，保持其他功能不变。有冲突请指出，不要猜。交付时逐条说明要求是否落实以及验证依据。

聊天网页中，可以上传简报和相关图片。只有文字简报时，AI 无法看到参考图。视频标记会自动带上该时刻的 JPEG 截图；AI 不支持视频时可以先看截图，动效仍需在可播放的结果中验证。

## 资料保存

- 清理浏览器或换设备不会自动迁移项目，请定期导出完整 ZIP 备份。
- 最多12份参考；单个文件≤30MB，项目约≤75MB。支持 PNG/JPG/WebP 和当前浏览器可播放的 MP4/WebM。
- 所有示例图形均为项目原创。上传的参考作品仍归原作者，不因导出而获得再分发许可。
- 五组示例不涵盖全部审美方向；个人参考、明确要求和未决定的部分都会保留。
